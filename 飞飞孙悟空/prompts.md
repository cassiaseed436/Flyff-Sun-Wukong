# 命令手册

## 命令：`【新建项目】`

### 逻辑说明

1. **零环境依赖（Zero-Config）**
   严格禁止生成 package.json、node_modules 或任何 serve.py 等服务器脚本。本项目完全依赖 Trae 内置的 Live Preview 插件进行实时渲染，无需手动启动任何本地服务器。
2. **物理库管理（Local Assets）**
   不使用在线 CDN，在根目录创建 `libs/` 文件夹。
   - **执行动作**：下载并存放 `p5.min.js`。
   - **目的**：确保在没有外部网络时，Live Preview 依然能正确解析 p5.js 环境，且路径引用必须为相对路径（如 `./libs/p5.min.js`）。
3. **标准脚手架（Standard Scaffold）**
   在根目录自动生成以下核心文件：
   - `index.html`：已配置好 `libs/` 路径引用。
   - `style.css`：包含全屏画布样式，隐藏滚动条。
   - `sketch.js`：预置 `setup()` 和 `draw()`。
4. **数据与资产预留**
   自动创建 `assets/data/` 和 `assets/svg/` 文件夹。
   > **特别注意**：在 `sketch.js` 中添加一行注释提醒："提示：如需加载 JSON/SVG 数据，请直接在 HTML 文件上右键选择「Open with Live Preview」，Live Preview 会自动处理跨域（CORS）限制。"

## 命令：`【备份：xxx】`

### 逻辑说明
1. **容器化封装**  
   将当前项目根目录下所有的核心 Web 文件（.js, .html, .css）打包。注意： 为了节省空间，默认不打包 assets/ 文件夹，但会在清单中记录素材引用路径。
2. **命名规范**  
   压缩包命名格式为：  
   `backup_yyyymmdd_xxx.zip`  
   例如：`backup_20260312_动态系统重构前.zip`
3. **存储路径**  
   所有生成的压缩包统一存放于项目根目录下的 `history/` 文件夹内。
4. **元数据嵌入（Manifest）**  
   在压缩包内部自动包含一个 `readme.md`，记录：  
   - 备份意图：`xxx`（由用户定义的备份原因）  
   - 时间戳：精确到秒的录入时间  
   - 环境快照：记录当前核心参数（如：`layoutMode`, `cols`, `rows`）  
   - 资产状态：列出当前项目引用的关键素材（如：SVG 数量，是否开启 PDF 导出）
5. **开发连续性**  
   确保解压该 ZIP 包后，其内部的文件结构能够直接在 p5.js 环境中运行，实现“无缝回滚”。

## 命令：`【版本恢复：xxx】`

### 逻辑说明
1. **目标定位**  
   在 `history/` 文件夹中搜索包含 `xxx` 关键词或对应日期时间戳的 `.zip` 备份文件。
2. **强制二次确认**  
   AI 在执行覆盖前，必须在终端弹出提示：  
   > ⚠️ 正在执行恢复操作：这将替换当前所有的核心 Web 文件（.js, .html, .css）。是否已对当前可能满意的修改执行了【备份】？
3. **安全缓冲**  
   在正式解压覆盖前，系统自动将当前工作区的文件打包为 `backup_AUTO_BEFORE_RESTORE.zip`，以防点错导致“双向丢失”。
4. **物理覆盖**  
   - 清空当前：删除项目根目录下所有的旧核心 Web 文件（.js, .html, .css）。  
   - 解压还原：将选定的 `backup_xxx.zip` 内容解压至根目录。
5. **环境重载**
   - 自动读取压缩包内的 `readme.md` 并显示在控制台，并通知我：  
     > 已回到：[备份名]，当时的状态是：[参数/视觉特征]  
   - 提示重启 p5.js 运行窗口。

## 素材备份：`【素材备份】`

### 逻辑
请将项目中 `data/` 文件夹中的所有素材打包成 zip 文件，另存到 `history/` 文件夹下，文件名为：`assets_时间戳（格式：yyyyMMddHHmmss）.zip`，用于项目素材备份。
